The industrial receipt server for thermal printers.

A simple and efficient ESC/POS printer server built with PHP, Workerman and ESC/POS-PHP — WebSocket-based printing for thermal receipt printers.

Get started Read the manual
escpos-printer-server / install 
$ curl -fsSL https://raw.githubusercontent.com/darkterminal/escpos-printer-server/main/scripts/install.sh | bash && cd ~/.local/share/escpos-printer-server && ./eps --role http

The features the day-to-day work needs

WebSocket receipt engine, multi-interface printer matrix, and a secure operator workflow — wrapped in one PHP server.

WebSocket core

Real-time receipt printing engine on Workerman with strict payload validation and single timestamped responses.

Multi-interface printer

CUPS, Ethernet, Linux-USB, SMB, Windows-USB and Windows-LPT printer interfaces.

POS operator ready

Built-in industrial Web GUI, cash drawer control and printer check tooling.

Secure by default

Optional shared token via EPS_AUTH_TOKEN; loopback by default.

Install in one command

Composer package plus the installer CLI — well, the installer plus the server binary.

shell 
$ curl -fsSL https://raw.githubusercontent.com/darkterminal/escpos-printer-server/main/scripts/install.sh | bash && cd ~/.local/share/escpos-printer-server && ./eps --role http

Windows: download the eps-windows-bundle from the Releases page and run eps-install.bat — the EPS-WS and EPS-HTTP services start automatically.

Before you run it

  • PHP >= 8.3 with sockets, intl, openssl
  • composer install for the dev repository
  • Rust nightly toolchain only when building from source

On first run

  • The installer downloads the Unix bundle and extracts it
  • The Web GUI is served from the bundled config/settings.html
  • You are ready to open a WebSocket print job
